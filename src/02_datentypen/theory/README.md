## 🎯 Theoretische Konzepte

### 1. Primitive Datentypen

- **int** - Ganze Zahlen
- **float** - Gleitkommazahlen
- **complex** - Komplexe Zahlen
- **bool** - Wahrheitswerte
- **str** - Zeichenketten

### 2. Collections (Sammlungen)

- **list** - Veränderbare, geordnete Sequenzen
- **tuple** - Unveränderbare, geordnete Sequenzen
- **dict** - Key-Value-Paare (Hash-Maps)
- **set** - Eindeutige Elemente (Mengen)

### 3. Erweiterte Konzepte

- **Type Conversion** - Konvertierung zwischen Typen
- **Type Checking** - Typ-Überprüfung zur Laufzeit
- **Mutability** - Veränderbarkeit von Objekten
- **Memory Management** - Speicherverwaltung
