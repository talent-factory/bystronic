# 💡 Examples - Demonstrationsbeispiele

Dieses Verzeichnis enthält praktische Beispiele, die die theoretischen Konzepte
von Datentypen und Datenstrukturen demonstrieren.

## 🎯 Beispiele

### Zahlentypen und mathematische Operationen

- **[numbers_demo.py](numbers_demo.py)** - Zahlen und mathematische Operationen

  - Integer, Float, Complex, Boolean
  - Mathematische Funktionen und Operatoren
  - Praktische Berechnungen für die Fertigung
  - **Schwierigkeit:** 🟢 Anfänger
  - **Zeit:** 10-15 Minuten

### String-Verarbeitung

- **[strings_demo.py](strings_demo.py)** - String-Manipulation und Formatierung

  - String-Methoden und Operationen
  - Formatierung mit f-strings
  - Text-Verarbeitung für Produktionsdaten
  - **Schwierigkeit:** 🟡 Fortgeschritten
  - **Zeit:** 15-20 Minuten

### Datenstrukturen

- **[collections_demo.py](collections_demo.py)** - Listen, Dictionaries, Sets und Tupel

  - Listen für dynamische Daten
  - Dictionaries für strukturierte Informationen
  - Sets für eindeutige Elemente
  - Tupel für unveränderliche Daten
  - **Schwierigkeit:** 🟡 Fortgeschritten
  - **Zeit:** 20-25 Minuten

### VBA-Migration

- **[vba_collections_comparison.py](vba_collections_comparison.py)** - VBA vs Python Collections

  - Arrays vs Listen
  - Collections vs Dictionaries
  - Variant vs dynamische Typen
  - Praktische Migrationstipps
  - **Schwierigkeit:** 🔴 Experte
  - **Zeit:** 25-30 Minuten

## 🚀 Ausführung

```bash
# Zahlen-Beispiele
uv run python src/02_datentypen/examples/numbers_demo.py

# String-Beispiele
uv run python src/02_datentypen/examples/strings_demo.py

# Collections-Beispiele
uv run python src/02_datentypen/examples/collections_demo.py

# VBA-Vergleich
uv run python src/02_datentypen/examples/vba_collections_comparison.py
```
