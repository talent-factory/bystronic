# 🟡 Intermediate Exercises - Fortgeschrittene Übungen

Übungen für Teilnehmer mit KI-Programmiererfahrung oder Python-Grundkenntnissen.

## 🎯 Charakteristika

- **Problemstellungen** mit weniger Vorgaben
- **Fokus auf Best Practices** und Code-Qualität
- **Erweiterte Aufgaben** mit zusätzlichen Anforderungen
- **Selbständige Problemlösung** mit gezielten Hilfen
- **Zeit pro Übung:** 25-40 Minuten

## 📚 Verfügbare Übungen

### Übung 1: Mitarbeiterprofil-System (🟡)

**Datei:** `uebung_01_personal_info_intermediate.py`

- Erweiterte Validierung und Fehlerbehandlung
- Datenklassen oder strukturierte Dictionaries
- Formatierte Ausgabe mit Rich-Text-Features
- **Lernziele:** Datenvalidierung, Strukturierung, Formatierung

### Übung 2: Wissenschaftlicher Taschenrechner (🟡)

**Datei:** `uebung_02_taschenrechner_intermediate.py`

- Erweiterte mathematische Funktionen
- Benutzerfreundliche Menüführung
- Verlaufspeicher und Wiederholung
- **Lernziele:** Modulare Programmierung, Benutzerführung

### Übung 3: Skill-Management-System (🟡)

**Datei:** `uebung_03_programmiersprachen_intermediate.py`

- Dictionary-basierte Datenstrukturen
- Such- und Filterfunktionen
- Datenexport und -import
- **Lernziele:** Datenstrukturen, Algorithmen, Persistierung

## 💡 Erweiterte Anforderungen

### Code-Qualität

- **Docstrings** für alle Funktionen
- **Type Hints** für Parameter und Rückgabewerte
- **Fehlerbehandlung** für Edge Cases
- **Modulare Struktur** mit klarer Trennung

### Best Practices

- **PEP 8** Konformität (Formatierung)
- **Aussagekräftige Variablennamen**
- **DRY-Prinzip** (Don't Repeat Yourself)
- **Kommentare** für komplexe Logik

## 🧪 Zusätzliche Herausforderungen

### Performance-Optimierung

- Effiziente Algorithmen wählen
- Speicherverbrauch optimieren
- Laufzeit-Komplexität beachten

### Erweiterbarkeit

- Code für zukünftige Erweiterungen vorbereiten
- Konfigurierbare Parameter
- Plugin-ähnliche Architektur

## ✅ Erfolgskriterien

- [ ] Alle Anforderungen vollständig erfüllt
- [ ] Code folgt Python Best Practices
- [ ] Robuste Fehlerbehandlung implementiert
- [ ] Performance ist angemessen optimiert
- [ ] Code ist gut dokumentiert

Nach erfolgreichem Abschluss können Sie:

- Best Practices der Python-Entwicklung anwenden
- Komplexe Datenstrukturen effektiv nutzen
