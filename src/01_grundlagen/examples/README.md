# 💡 Examples - Demonstrationsbeispiele

Dieses Verzeichnis enthält praktische Beispiele, die die theoretischen Konzepte
demonstrieren.

## 🎯 Beispiele

### Grundlegende Demonstrationen

- **[hello_world.py](hello_world.py)** - Ihr erstes Python-Programm

  - Einfache Ausgaben und Variablen
  - String-Formatierung (f-strings)
  - Interaktive Eingaben
  - **Schwierigkeit:** 🟢 Anfänger
  - **Zeit:** 5-10 Minuten

- **[vba_vs_python.py](vba_vs_python.py)** - Praktischer Vergleich VBA vs Python

  - Listen vs Arrays
  - Dictionaries vs Collections
  - Funktionen und Fehlerbehandlung
  - Moderne Python-Features
  - **Schwierigkeit:** 🟡 Fortgeschritten
  - **Zeit:** 15-20 Minuten

## 🚀 Ausführung

```bash
# Hello World Beispiel
uv run python src/01_grundlagen/examples/hello_world.py

# VBA vs Python Vergleich
uv run python src/01_grundlagen/examples/vba_vs_python.py
```
